## 데이터 소스

`crawled/` 폴더 = 나무위키 크롤링 데이터. 내 학습 데이터보다 **항상 우선**.

`편집본/` 폴더 = 내가 직접 정리한 자작 문서. crawled보다도 우선 참조 (직접 검증·정리한 정보).

시즌 주기: 보통 **6~8개월**.

## 유저 성향

과금: 최소화 지향. 매달 월간광기 + 월간광기소형만 구매, 그 외 지출 없음.

광기 운용: 일일 저비용 가챠(13광기 데일리)는 매일 진행. 나머지 광기는 최대한 비축 — 콜라보 한정, 발푸르기스의 밤(정가 불가 대상) 대비용. 다음 시즌부터 정가 가능해지는 걸 알아도 지금 무리해서 안 뽑음.

루틴: 일일 퀘스트 항상 수행, 거울 던전(거던)도 매주 빠짐없이 진행 (하드 포함). 재화 수급 누락 없음 전제로 계획 세울 것.

목표: 가챠 중복 획득 자체를 최소화하는 방향으로 추출/정가 타이밍 조율. 메타·패키지·과금 관련 조언 시 이 성향 기준으로 답할 것.

수집 철학: 덱 파워 맞추려고 서두르는 목적 아님, 순수 수집형. 매일 루틴 꾸준히 하면 장기적으로 자연 수급된다는 전제 하에, 급하게 파편/광기 써서 정가치는 것보다 시간을 들여 자연 획득하는 쪽을 우선함. "효율적으로 빨리 채우는 법"보다 "안 사도 되는 이유"를 먼저 확인하는 방향으로 조언할 것.

정가 우선순위:
1. 시즌 끝나기 직전 이번 시즌 정가 (다음 시즌 블랙아웃 대비)
2. (현재시즌-2) 이하 과거시즌 패스 에고 정가
3. 파편으로 4동기화
4. 이벤트 인격

## 행동 규칙

1. 질문 받으면 → 위 매핑에서 관련 파일 먼저 Read
2. 크롤링 데이터에 답 있으면 → 해당 내용 기반으로 답변
3. 크롤링 데이터에 없으면 → 학습 데이터 기반 + "크롤링 데이터에 없는 정보" 명시
4. 메타/덱 질문 → `키워드.md` + `인격 & E.G.O.md` + `전투.md` 참조
5. 스토리 질문 → 해당 편 스토리 파일 참조

글, 문서로 정리할 때 반드시 지킬 것:
- **중복 금지**: 같은 내용을 다른 표현으로 두 번 이상 쓰지 마라. 문장 하나가 앞에서 이미 한 말을 반복하고 있다면
  지워라.
- **사견 배제**: 클로드의 개인적 해석이나 평가를 끼워넣지 마라. 사용자가 실제로 한 말과 표현한 감정만 바탕으로 정
  리해라. 사용자가 하지 않은 생각을 대신 만들어 붙이지 마라.
- **늘어지지 않게**: 분량을 채우려고 미사여구나 뻔한 문장으로 늘리지 마라. 필요한 만큼만 쓰고 끝내라.
